# Z-Tally

<p align="center">
  <img src="./release/icon-240.png" alt="Z-Tally app icon" width="160">
</p>

An offline tally counter app for Amazfit watches running Zepp OS. Z-Tally 1.2.1 provides five independent counters, local history, a SecondaryWidget, and read-only viewing of the current result plus up to 10 reset-history entries from Z-Tally Move on round and 390×450 square displays.

Z-Tally 1.2.1 是一款面向 Zepp OS Amazfit 手表的离线按压计数器应用，提供五组独立计数、本地历史记录、副屏计数，以及 Z-Tally Move 当前结果与最多 10 条清零历史的只读查看功能。

- Works fully offline / 完全离线运行
- No account, ads, or cloud sync / 无账号、广告或云同步
- 8 languages: English, Simplified/Traditional Chinese, Spanish, Portuguese, Italian, German, and Russian / 支持 8 种语言
- Round and 390×450 square displays / 支持圆屏与 390×450 方屏
- SecondaryWidget quick counting / 支持副屏快速计数
- Read-only current and reset-history results from Z-Tally Move / 只读查看 Z-Tally Move 当前与清零历史结果
